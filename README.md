# A-Hybrid-Quantum-Classical-Approach-to-Binary-Classification-Using-Variational-Quantum-Circuits-
This project studies a hybrid quantum–classical approach for binary classification. Quantum features generated by a Variational Quantum Circuit (VQC) in Qiskit are used with scikit-learn classifiers and compared with classical models.The emphasis is on reproducibility and fair evaluation rather than demonstrating quantum advantage.
